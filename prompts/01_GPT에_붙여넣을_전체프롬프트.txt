첨부한 GPT_제공파일.zip을 사용해서 Windows 바탕화면용 ‘치이카와 타이머 3종’을 만들어 주세요.
이 요청은 아이디어를 새로 디자인하는 작업이 아니라, 첨부된 최종 Python 프로그램을 같은 동작과 모습으로 재현하는 작업입니다. 자세한 기준은 02_재현_상세명세.txt에 있습니다.

완성 목표
Windows 바탕화면에 투명한 공부 캐릭터가 떠 있습니다. 캐릭터를 드래그해 이동하고 우클릭하면 작고 둥근 설정 메뉴가 커서 오른쪽에 뜹니다. 타이머를 설정하면 캐릭터 주변에 원형 진행 표시, 남은 시간, 원을 따라 이동하는 세이렌과 인어 두 마리가 나타납니다. 완료되면 원·숫자·세이렌·인어가 함께 1.8초 동안 사라지고 캐릭터가 점프와 색종이로 축하하며 캐릭터별 음악이 재생됩니다. 치이카와, 하치와레, 우사기를 선택할 수 있습니다.

가장 중요한 규칙
1. ZIP을 실제로 열어 파일 목록과 내용부터 확인하세요. 첨부 파일을 읽지 못했다면 읽은 척하지 말고 알려주세요.
2. reference/chiikawa_timer.py의 구현이 최종 기준입니다. 같은 결과를 위해 이 코드와 create_shortcut.py를 보존하고, assets를 바이트 단위로 그대로 복사하는 것을 우선하세요. 임의로 리팩터링하거나 다른 프레임워크로 옮기지 마세요.
3. ‘같은 결과’가 목표이므로 사소한 기존 동작도 임의로 개선하지 마세요. 신규 기능, 설치 프로그램, 자동 시작, 로그인, 외부 통신, 광고, 다른 테마, 설정 패널, 위치 편집 UI는 추가하지 마세요.
4. 이미지/스프라이트/음악/폰트를 다시 그리거나 생성하거나 재압축하지 마세요. 파일 이름과 경로를 그대로 유지하세요. YouTube 다운로드나 재추출 작업은 필요하지 않습니다.
5. 기준 자산과 소스의 SHA256을 기준정보.json과 비교하고 누락/손상 여부를 확인하세요.
6. 숫자는 Qt의 논리 픽셀입니다. 모니터 배율을 좌표에 직접 곱하지 마세요. devicePixelRatioF는 작은 PNG 렌더링용 이미지 캐시에 사용합니다.
7. 출력물은 사용자가 Python과 필요한 라이브러리를 설치한 뒤 소스 그대로 실행하는 방식입니다. EXE, Godot, Electron, React, 브라우저 앱, MSIX를 기본 결과에 넣지 마세요.

핵심 동작
- QWidget 기반의 380×380 투명/프레임 없는 Qt.Tool 창. 기본 항상 위. 프로그램 종료는 메뉴/트레이에서 명시적으로 수행.
- app.setQuitOnLastWindowClosed(False)는 필수. Qt.Tool은 일반 주 창으로 계산되지 않아 커스텀 입력창이 닫힐 때 앱이 종료되던 문제가 있었으므로 True로 바꾸지 마세요.
- 초기 캐릭터는 저장된 설정이 없으면 우사기. 평상시 공부 3프레임만 표시. 원과 시간은 표시하지 않음.
- 공부 프레임은 초당 3회 교체, 긴 변 165px, 중심 (182.49, 175.9290576171875).
- 원 중심 (190,190), 반지름 103, 선 두께 9. 공부 캐릭터와 원의 상대 배치를 고정하고 창 전체를 드래그.
- 시간은 원 안쪽 캐릭터 아래, 글자 기준선 중앙 (191,268.9090576171875), 19px 굵은 Pretendard. 실제 텍스트 폭의 절반을 빼 중앙 정렬.
- 타이머는 time.monotonic의 deadline 기준. 시간은 ceil(remaining), 분:초 두 자리 형식. 실제 경과 시간 기반으로 프레임 지연을 보정.
- 진행 중 원/시간의 색상이 초록→노랑→빨강으로 변함. 세이렌 얼굴이나 이미지 색상은 변하지 않음.
- 세이렌 64px, 인어 두 마리 각각 40px. 같은 원 궤도에서 세이렌을 따라 시계 방향으로 이동. 두 인어의 간격은 원본 수식 그대로.
- 완료 시 원·시간·세이렌·인어는 같이 1.8초 페이드. 세이렌/인어는 108px 왼쪽으로 물러남. 캐릭터는 즉시 완료 모션.
- 완료 중심 (190,178), 우사기 폭165/치이카와와 하치와레 폭132. 점프 높이 abs(sin(elapsed*7))*12. 스프라이트 한 칸192×208.
- 색종이20개와 음표 두 개. 원본에 있는 위치·색상·움직임 수식을 그대로 사용.
- 완료 공연: 치이카와27초, 하치와레57초, 우사기16초. 음악 옵션을 꺼도 해당 시간 동안 완료 모션 유지. 끝나면 공부로 복귀하며 원·시간은 계속 숨김.
- 노래는 제공된 FLAC 파일, 이미 동일한 -18 LUFS로 조정된 자료. QMediaPlayer/QAudioOutput volume1.0. 재정규화나 볼륨 변경 없음.
- 세이렌 표시를 끄면 세이렌과 두 인어만 숨김. 진행 원과 시간은 유지.
- 공부 상태 시간 없음, 일시정지 글자 없음, 완료 후 원/시간 없음.

설정 메뉴
- 첫 메뉴는 ‘타이머 설정’, ‘캐릭터 설정’ 두 버튼.
- 캐릭터 순서 ‘치이카와’, ‘하치와레’, ‘우사기’. 현재 캐릭터만 선택 강조.
- 대기 메뉴: ‘타이머 설정’ 제목, ‘15분’, ‘30분’, ‘60분’, ‘커스텀’, 구분선, ‘✓ 세이렌 표시’, ‘✓ 완료 노래’, ‘종료’. 체크가 꺼지면 ✓만 제거.
- 실행 중에는 ‘일시정지’/‘계속하기’, ‘타이머 해제’, ‘세이렌 표시’, ‘완료 노래’ 네 동작만. ‘종료’, 프리셋, 시작하기 버튼은 이 메뉴에 없음. 실행 중 앱 종료는 트레이 메뉴 사용.
- 세이렌/완료 노래는 일반 글씨/일반 배경. 클릭해도 메뉴 닫지 않음. 전체 버튼을 색칠하거나 굵게 만들지 않음.
- 메뉴 폭120px, 버튼 높이28px, 텍스트12px, 버튼패딩6px, 둥근카드9px, 커서 오른쪽8px에 표시, 화면 가장자리에 맞춰 클램프.
- 커스텀은 작은 분 입력창: 바깥232px, 카드200px. QLineEdit+QIntValidator(1,180), ‘분’, 취소/시작만. 초/시/슬라이더/별도 큰 화면 없음.
- 설정 창은 동시에 하나. 교체 시 옛 창을 닫고 해제. 커스텀 창 닫힘 뒤 새 팝업은30ms 지연 표시.
- QPopup 카드 자체 그림자와 네모 배경은 넣지 않음. 커스텀 입력창의 그림자는 기준 코드 그대로.

상태·입력·저장
- Countdown은 ready/running/paused/finished. stop은 ready로, 일시정지는 남은 시간 고정, 재개는 deadline 갱신.
- 투명 여백은 WM_NCHITTEST의 HTTRANSPARENT(-1)로 바탕화면 클릭 전달. QCursor.pos/mapFromGlobal 사용.
- 마우스 드래그는 globalPosition 기반. 원과 숫자를 별도 창에 띄우지 않음.
- 알림 영역 아이콘은 선택한 캐릭터의 공부3프레임으로 초당3회 교체. 아이콘32×32, 그림30×30 이내.
- 트레이 메뉴는 ‘설정’, ‘오른쪽 아래로 이동’, ‘종료’.
- 설정은 %APPDATA%/chiikawa_timer_python/settings.json에 저장. 저장 대상 character/sound/show_siren/on_top/reminders/duration/position. 실행 중 남은 시간은 복원하지 않음.
- 파일 손상/위치 화면밖/타이머 범위 오류는 기준 코드와 같은 방식으로 처리. 실제 파일 누락은 실행 오류 안내.
- 15분마다6초 동안 하단 스트레칭 알림이 표시되는 기존 동작도 보존. 추가 메뉴는 만들지 않음.
- --demo는12초 체험, --character는chiikawa/hachiware/usagi. 명령행 지원.

Python 소스와 Windows 바로가기 실행
BAT나 별도 EXE를 만들지 마세요. reference/create_shortcut.py와 chiikawa_timer.ico를 결과 프로그램 폴더에 넣으세요. 사용자는 처음 한 번 같은 Python 환경에서 다음 두 명령을 실행합니다.
  py -m pip install -r requirements.txt
  py create_shortcut.py
두 번째 명령은 프로그램 폴더에 ‘치이카와 타이머.lnk’를 생성합니다. 더블클릭하면 pythonw.exe가 chiikawa_timer.py를 실행하여 콘솔 창 없이 캐릭터만 표시합니다.
배포 ZIP에는 제작자의 PC 경로가 들어간 .lnk를 넣지 마세요. .lnk는 사용자 PC에서 생성합니다. 완성 기준 코드의 바로가기 생성기를 그대로 사용하세요.
생성기는 sys.executable 옆의 pythonw.exe를 선택해야 합니다. pip 설치한 환경과 같은 인터프리터를 사용하고, pythonw 존재/프로그램 폴더/Qt 의존성을 검사하세요. Windows Shell COM의 IShellLinkW/IPersistFile API로 작성합니다. 별도 BAT, PowerShell 파일, 다운로드한 런처 EXE, 외부 라이브러리를 추가하지 않습니다.
바로가기 TargetPath=절대 pythonw.exe 경로, Arguments=따옴표로 감싼 절대 chiikawa_timer.py 경로, WorkingDirectory=프로그램 폴더, IconLocation=동봉 chiikawa_timer.ico, ShowCmd=1입니다.
사용자가 폴더나 Python을 옮기면 바로가기를 재생성한다는 안내를 반드시 포함하세요. 생성용 터미널은 닫아도 타이머가 유지되지만, 실제 타이머 Python 프로세스를 종료하면 타이머가 종료됩니다.
원본 main의 setQuitOnLastWindowClosed(False)를 보존하세요. 바로가기 실행에서도 커스텀 입력창 종료가 앱 종료로 이어지면 안 됩니다.
보안 설정이나 레지스트리, 인증서 저장소를 변경하지 마세요. Windows .lnk는 코드 서명 인증서가 아니며 스마트 앱 컨트롤의 차단을 없앤다고 주장하지 마세요.

필수 검증

- three characters의 공부/실행/완료와 12초 데모.
- 커스텀 시작/취소 뒤 app.exec 이벤트 루프가 실제 계속 실행되는지 확인.

```python
CENTER = QPointF(190, 190)
RADIUS = 103
STUDY_OFFSET = QPointF(-10, -9.0909423828125)
FINISH_OFFSET = QPointF(0, -12)
TIME_OFFSET = QPointF(11, -15)


@dataclass
class Countdown:
    duration: float = 900
    remaining: float = 900
    state: str = 'ready'
    deadline: float = 0
    finished_at: float = 0

    def start(self, seconds: float, now: float):
        if not math.isfinite(seconds) or not 1 <= seconds <= 10800:
            raise ValueError('Timer duration must be 1–10800 seconds')
        self.duration = self.remaining = seconds
        self.deadline = now + seconds
        self.state = 'running'
        self.finished_at = 0

    def tick(self, now: float) -> bool:
        if self.state == 'running':
            self.remaining = max(0, self.deadline - now)
            if self.remaining == 0:
                self.state = 'finished'
                self.finished_at = now
                return True
        return False

    def pause_resume(self, now: float) -> bool:
        completed = self.tick(now)
        if self.state == 'running':
            self.state = 'paused'
        elif self.state == 'paused':
            self.deadline = now + self.remaining
            self.state = 'running'
        return completed

    def stop(self):
        self.state = 'ready'
        self.remaining = self.duration
        self.finished_at = 0

    @property
    def progress(self):
        return max(0, min(1, 1 - self.remaining / self.duration))

    def fade(self, now):
        if self.state == 'ready':
            return 0
        return max(0, 1 - (now - self.finished_at) / 1.8) if self.state == 'finished' else 1


def blend(a, b, fraction):
    a, b = QColor(a), QColor(b)
    return QColor(*(round(x + (y-x)*fraction) for x, y in zip(a.getRgb()[:3], b.getRgb()[:3])))


def urgency(fraction):
    return blend('#8dcfa8', '#eeb45b', fraction/.55) if fraction < .55 else blend('#eeb45b', '#e6454a', (fraction-.55)/.45)


def orbit(fraction, offset=0):
    angle = -math.pi/2 + fraction*math.tau + offset
    return CENTER + QPointF(math.cos(angle)*RADIUS, math.sin(angle)*RADIUS)


def sprite_frame(elapsed, row):
    holds = [140, 140, 140, 280] if row == 3 else [140, 140, 140, 140, 280]
    offset = elapsed*1000 % sum(holds)
    for i, hold in enumerate(holds):
        if offset < hold:
            return i
        offset -= hold
    return 0


class Popup(QWidget):
    """A compact, non-modal settings panel anchored to the cursor."""
    def __init__(self, owner, anchor, heading=None):
        super().__init__(owner, Qt.WindowType.Popup | Qt.WindowType.FramelessWindowHint | Qt.WindowType.NoDropShadowWindowHint)
        self.setAttribute(Qt.WidgetAttribute.WA_TranslucentBackground)
        self.anchor = QPoint(anchor)
        # One painted rounded card; no native window frame or second shadow panel.
        self.setObjectName('popupWindow')
        outer = QVBoxLayout(self)
        outer.setContentsMargins(0, 0, 0, 0)
        self.card = QWidget()
        self.card.setObjectName('contextMenu')
        outer.addWidget(self.card)
        self.setStyleSheet('''QWidget#popupWindow, QWidget#contextMenu { background:transparent; border:0; }
            QPushButton { color:#343b43; background:transparent; border:0; border-radius:6px;
                padding:6px; font-size:12px; font-weight:normal; text-align:left; }
            QPushButton:hover { background:#e9f1ea; }
            QPushButton[selected="true"] { background:#e9f1ea; font-weight:700; }
            QLabel#menuTitle { color:#8a938d; font-size:10px; background:transparent; border:0; }
            QFrame#separator { background:#eaece8; border:0; }''')
        self.column = QVBoxLayout(self.card)
        self.column.setContentsMargins(6, 6, 6, 6)
        self.column.setSpacing(0)
        if heading:
            title = QLabel(heading)
            title.setObjectName('menuTitle')
            title.setContentsMargins(6, 5, 6, 5)
            self.column.addWidget(title)
        self.setFixedWidth(120)

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QPainter.RenderHint.Antialiasing)
        painter.setPen(QPen(QColor('#dededb'), 1))
        painter.setBrush(QColor(255, 255, 255, 245))
        painter.drawRoundedRect(QRectF(self.rect()).adjusted(.5, .5, -.5, -.5), 9, 9)

    def button(self, text, callback, close=True):
        button = QPushButton(text)
        button.setFixedHeight(28)
        button.setCursor(Qt.CursorShape.PointingHandCursor)
        self.column.addWidget(button)
        def clicked():
            if close:
                self.hide()
            callback()
        button.clicked.connect(clicked)
        return button

    def separator(self):
        row = QWidget()
        layout = QVBoxLayout(row)
        layout.setContentsMargins(4, 5, 4, 5)
        line = QFrame()
        line.setObjectName('separator')
        line.setFixedHeight(1)
        layout.addWidget(line)
        self.column.addWidget(row)

    def display(self):
        self.adjustSize()
        area = (QApplication.screenAt(self.anchor) or QApplication.primaryScreen()).availableGeometry()
        self.move(max(area.left(), min(self.anchor.x(), area.right()-self.width()+1)),
                  max(area.top(), min(self.anchor.y(), area.bottom()-self.height()+1)))
        if getattr(self, 'wait_for_dialog_close', False):
            QTimer.singleShot(30, self.show)
        else:
            self.show()


class TimerPet(QWidget):
    def __init__(self, *, persist=True, clock=time.monotonic):
        super().__init__()
        self.clock = clock
        self.model = Countdown()
        self.persist = persist
        self.settings_path = Path(os.getenv('APPDATA', str(Path.home()))) / 'chiikawa_timer_python' / 'settings.json'
        self.character = 'usagi'
        self.sound = self.show_siren = self.on_top = self.reminders = True
        self.font_family = 'Segoe UI'
        for name in ['Pretendard-Regular.otf', 'Pretendard-Bold.otf']:
            font_id = QFontDatabase.addApplicationFont(str(ASSETS/name))
            if font_id >= 0:
                self.font_family = QFontDatabase.applicationFontFamilies(font_id)[0]
        self.setFont(self.font(12))
        self.study = {key: [self.load_pixmap(f'{key}/study-{i}.png') for i in range(1, 4)] for key in NAMES}
        self.study_icons = {key: [self.make_study_icon(frame) for frame in frames]
                            for key, frames in self.study.items()}
        self.icon_frame = -1
        self.sheets = {key: self.load_pixmap(f'{key}/spritesheet.png') for key in NAMES}
        self.siren = self.load_pixmap('siren.png')
        self.mermaid = self.load_pixmap('mermaid.png')
        self.scaled_images = {}
        for key in NAMES:
            if not (ASSETS/f'{key}-complete.flac').is_file():
                raise FileNotFoundError(f'Missing completion song: {key}')
        self.player = QMediaPlayer(self)
        self.audio = QAudioOutput(self)
        self.audio.setVolume(1.0)  # Lossless FLAC tracks already normalized to the same -18 LUFS.
        self.player.setAudioOutput(self.audio)
        self.player.errorOccurred.connect(self.audio_error)
        self.audio_error_text = ''
        self.popup = None
        self.drag_offset = None
        self.custom_dialog = None
        self.started_at = self.clock()
        self.last_reminder = self.started_at
        self.toast_until = 0
        self.finish_duration = SONG_SECONDS[self.character]
        saved_position = self.load_settings() if persist else None
        self.setWindowFlags(Qt.WindowType.Tool | Qt.WindowType.FramelessWindowHint |
                            (Qt.WindowType.WindowStaysOnTopHint if self.on_top else Qt.WindowType.Widget))
        self.setAttribute(Qt.WidgetAttribute.WA_TranslucentBackground)
        self.setFixedSize(380, 380)
        self.setWindowTitle('치이카와 타이머 3종 · Python')
        self.setWindowIcon(self.study_icons[self.character][0])
        self.dock()
        if saved_position:
            self.restore_position(QPoint(*saved_position))
        self.tray = None
        if QSystemTrayIcon.isSystemTrayAvailable():
            self.tray = QSystemTrayIcon(self.windowIcon(), self)
            self.tray.setToolTip('치이카와 타이머 3종')
            menu = QMenu(self)
            menu.addAction('설정', lambda: self.show_home(self.pos()+QPoint(190, 190)))
            menu.addAction('오른쪽 아래로 이동', self.dock)
            menu.addAction('종료', self.close)
            self.tray.setContextMenu(menu)
            self.tray.activated.connect(lambda reason: self.show_home(self.pos()+QPoint(190, 190)) if reason == QSystemTrayIcon.ActivationReason.Trigger else None)
            self.tray.show()
        self.animation = QTimer(self)
        self.animation.setTimerType(Qt.TimerType.PreciseTimer)
        self.animation.timeout.connect(self.tick)
        self.animation.start(16)

    def font(self, pixels, bold=False):
        font = QFont(self.font_family)
        font.setPixelSize(pixels)
        font.setBold(bold)
        return font

    @staticmethod
    def load_pixmap(name):
        result = QPixmap(str(ASSETS/name))
        if result.isNull():
            raise FileNotFoundError(f'Missing or invalid image: {ASSETS/name}')
        return result

    @staticmethod
    def make_study_icon(frame):
        icon = QPixmap(32, 32)
        icon.fill(Qt.GlobalColor.transparent)
        scaled = frame.scaled(30, 30, Qt.AspectRatioMode.KeepAspectRatio,
                              Qt.TransformationMode.SmoothTransformation)
        painter = QPainter(icon)
        painter.drawPixmap((32-scaled.width())//2, (32-scaled.height())//2, scaled)
        painter.end()
        return QIcon(icon)

    def update_study_icon(self, now):
        frame = int((now-self.started_at)*3)%3
        if frame != self.icon_frame:
            self.icon_frame = frame
            icon = self.study_icons[self.character][frame]
            self.setWindowIcon(icon)
            if self.tray:
                self.tray.setIcon(icon)
                self.tray.setToolTip(NAMES[self.character]+' · 치이카와 타이머')

    def load_settings(self):
        try:
            data = json.loads(self.settings_path.read_text(encoding='utf-8'))
            if data.get('character') in NAMES:
                self.character = data['character']
            for key in ['sound', 'show_siren', 'on_top', 'reminders']:
                if isinstance(data.get(key), bool):
                    setattr(self, key, data[key])
            seconds = data.get('duration', 900)
            if isinstance(seconds, (int, float)) and math.isfinite(seconds) and 1 <= seconds <= 10800:
                self.model.duration = self.model.remaining = seconds
            pos = data.get('position')
            if isinstance(pos, list) and len(pos) == 2 and all(isinstance(x, int) for x in pos):
                return pos
        except (OSError, ValueError, TypeError):
            pass
        return None

    def save_settings(self):
        if not self.persist:
            return
        data = {key: getattr(self, key) for key in ['character', 'sound', 'show_siren', 'on_top', 'reminders']}
        data.update(duration=self.model.duration, position=[self.x(), self.y()])
        try:
            self.settings_path.parent.mkdir(parents=True, exist_ok=True)
            temporary = self.settings_path.with_suffix('.tmp')
            temporary.write_text(json.dumps(data, ensure_ascii=False), encoding='utf-8')
            temporary.replace(self.settings_path)
        except OSError as error:
            print(f'Cannot save preferences: {error}', file=sys.stderr)

    def restore_position(self, point):
        screen = QApplication.screenAt(point+QPoint(190, 190)) or QApplication.primaryScreen()
        area = screen.availableGeometry()
        self.move(max(area.left()-80, min(point.x(), area.right()-300)),
                  max(area.top()-80, min(point.y(), area.bottom()-300)))

    def dock(self):
        screen = self.screen() or QApplication.primaryScreen()
        area = screen.availableGeometry()
        target = QPoint(1567-190, 724-190)
        self.move(max(area.left(), min(target.x(), area.right()-379)),
                  max(area.top(), min(target.y(), area.bottom()-379)))

    def begin(self, seconds):
        self.player.stop()
        self.model.start(seconds, self.clock())
        self.save_settings()
        self.update()

    def stop(self):
        self.player.stop()
        self.model.stop()
        self.update()

    def pause_resume(self):
        if self.model.pause_resume(self.clock()):
            self.complete()
        self.update()

    def complete(self):
        self.finish_duration = SONG_SECONDS[self.character]
        self.player.stop()
        self.player.setSource(QUrl.fromLocalFile(str(ASSETS/f'{self.character}-complete.flac')))
        if self.sound:
            self.player.play()

    def tick(self):
        now = self.clock()
        self.update_study_icon(now)
        if self.model.tick(now):
            self.complete()
        if (self.model.state == 'finished' and now-self.model.finished_at >= self.finish_duration
                and self.player.playbackState() != QMediaPlayer.PlaybackState.StoppedState):
            self.player.stop()
        if self.reminders and now-self.last_reminder >= 900:
            self.last_reminder = now
            self.toast_until = now+6
        self.update()

    def audio_error(self, error, message):
        self.audio_error_text = message
        print(f'Audio playback error: {message}', file=sys.stderr)
        if self.tray:
            self.tray.showMessage('완료 음악을 재생하지 못했어요', message)

    def image(self, painter, pixmap, center, side, flip=False, alpha=1):
        size = pixmap.size()
        factor = side/max(size.width(), size.height())
        width, height = size.width()*factor, size.height()*factor
        # Pre-filter large PNGs once at the monitor's actual pixel density;
        # drawing a 1536px image directly at 64px can make fine outlines flicker.
        density = self.devicePixelRatioF()
        key = (pixmap.cacheKey(), side, density)
        if key not in self.scaled_images:
            self.scaled_images[key] = pixmap.scaled(
                QSize(max(1, round(width*density)), max(1, round(height*density))),
                Qt.AspectRatioMode.KeepAspectRatio, Qt.TransformationMode.SmoothTransformation)
        pixmap = self.scaled_images[key]
        painter.save()
        painter.setOpacity(alpha)
        painter.translate(center)
        if flip:
            painter.scale(-1, 1)
        painter.drawPixmap(QRectF(-width/2, -height/2, width, height), pixmap, QRectF(pixmap.rect()))
        painter.restore()

    def paintEvent(self, event):
        now = self.clock()
        p = QPainter(self)
        p.setRenderHints(QPainter.RenderHint.Antialiasing | QPainter.RenderHint.SmoothPixmapTransform)
        fade, progress = self.model.fade(now), self.model.progress
        finished = self.model.state == 'finished'
        if fade > 0:
            p.save()
            p.setOpacity(fade)
            track = blend('#e5e9e7', '#f7d3d7', progress)
            p.setPen(QPen(track, 9, Qt.PenStyle.SolidLine, Qt.PenCapStyle.RoundCap))
            p.drawEllipse(CENTER, RADIUS, RADIUS)
            if progress > 0:
                path = QPainterPath()
                path.moveTo(orbit(0))
                for i in range(1, 129):
                    path.lineTo(orbit(progress*i/128))
                p.setPen(QPen(urgency(progress), 9, Qt.PenStyle.SolidLine, Qt.PenCapStyle.RoundCap))
                p.drawPath(path)
            count = math.ceil(self.model.remaining)
            value = f'{count//60:02}:{count%60:02}'
            p.setFont(self.font(19, True))
            p.setPen(blend('#343b43', '#cf3342', progress))
            anchor = CENTER+STUDY_OFFSET+TIME_OFFSET+QPointF(0, 103)
            p.drawText(anchor-QPointF(p.fontMetrics().horizontalAdvance(value)/2, 0), value)
            p.restore()
            if self.show_siren:
                spacing = max(.48, 2*math.asin(58/(2*RADIUS)))
                pair = 2*math.asin(34/(2*RADIUS))
                for i, offset in enumerate([0, spacing, spacing+pair]):
                    pos = orbit(progress, -offset)
                    if finished:
                        pos.setX(pos.x()-(1-fade)*108)
                    angle = -math.pi/2+progress*math.tau-offset
                    self.image(p, self.siren if i == 0 else self.mermaid, pos,
                               64 if i == 0 else 40, math.sin(angle)>0 or finished, fade)
        elapsed = now-self.model.finished_at
        if finished and elapsed < self.finish_duration:
            row = 4 if int(elapsed*2)%2 == 0 else 3
            frame = sprite_frame(elapsed, row)
            width = 165 if self.character == 'usagi' else 132
            height = width*208/192
            pos = CENTER+FINISH_OFFSET-QPointF(width/2, height/2+abs(math.sin(elapsed*7))*12)
            p.drawPixmap(QRectF(pos.x(), pos.y(), width, height), self.sheets[self.character], QRectF(frame*192, row*208, 192, 208))
            p.setPen(Qt.PenStyle.NoPen)
            for i in range(20):
                fraction = (elapsed*.65+i*.137)%1
                p.setBrush(QColor(['#f2bd6f', '#99bdfa', '#eaa1ba', '#a1d4b4'][i%4]))
                p.drawRect(QRectF(100+(i*41)%180+math.sin(fraction*8+i)*8, 65+fraction*230, 3, 5))
            p.setFont(self.font(18))
            p.setPen(QColor('#e9b758')); p.drawText(QPointF(90, 140), '♪')
            p.setPen(QColor('#8db5f2')); p.drawText(QPointF(270, 115), '♫')
        else:
            frame = int((now-self.started_at)*3)%3
            self.image(p, self.study[self.character][frame], CENTER+STUDY_OFFSET+QPointF(2.49, -4.98), 165)
        if now < self.toast_until:
            p.setPen(Qt.PenStyle.NoPen); p.setBrush(QColor('#fff8df'))
            p.drawRoundedRect(QRectF(45, 350, 290, 25), 10, 10)
            p.setFont(self.font(10)); p.setPen(QColor('#626057'))
            p.drawText(QRectF(45, 350, 290, 25), Qt.AlignmentFlag.AlignCenter, '물 마시고 잠깐 스트레칭해요!')

    def interactive(self, point):
        if self.clock() < self.toast_until and QRectF(45, 350, 290, 25).contains(point):
            return True
        if self.model.state in ['running', 'paused'] or (self.model.state == 'finished' and self.model.fade(self.clock()) > 0):
            return math.hypot(point.x()-190, point.y()-190) <= 176
        pos = CENTER+(FINISH_OFFSET if self.model.state == 'finished' and self.clock()-self.model.finished_at < self.finish_duration else STUDY_OFFSET)
        return QRectF(pos.x()-89, pos.y()-105, 178, 210).contains(point)

    def nativeEvent(self, event_type, message):
        if sys.platform == 'win32':
            import ctypes
            from ctypes import wintypes
            msg = wintypes.MSG.from_address(int(message))
            if msg.message == 0x84:  # WM_NCHITTEST: let empty desktop area receive input.
                # Qt's global cursor coordinates account for per-monitor DPI.
                if not self.interactive(self.mapFromGlobal(QCursor.pos())):
                    return True, -1  # HTTRANSPARENT
        return super().nativeEvent(event_type, message)

    def mousePressEvent(self, event):
        if event.button() == Qt.MouseButton.LeftButton and self.interactive(event.position()):
            self.drag_offset = event.globalPosition().toPoint()-self.pos()
            event.accept()

    def mouseMoveEvent(self, event):
        if self.drag_offset is not None:
            self.move(event.globalPosition().toPoint()-self.drag_offset)

    def mouseReleaseEvent(self, event):
        if self.drag_offset is not None:
            self.drag_offset = None
            self.save_settings()

    def contextMenuEvent(self, event):
        if self.interactive(event.pos()):
            self.show_home(event.globalPos()+QPoint(8, 0))

    def dismiss_settings(self):
        popup, dialog = self.popup, self.custom_dialog
        self.popup = self.custom_dialog = None
        if popup:
            popup.close()
            popup.deleteLater()
        if dialog:
            dialog.reject()
            # Dispose the old native dialog before activating its replacement.
            # Otherwise its delayed destruction can dismiss the new Qt popup.
            QCoreApplication.sendPostedEvents(dialog, QEvent.Type.DeferredDelete)

    def make_popup(self, anchor, title=None):
        replacing_dialog = self.custom_dialog is not None
        self.dismiss_settings()
        self.popup = Popup(self, anchor, title)
        self.popup.wait_for_dialog_close = replacing_dialog
        return self.popup

    def show_home(self, anchor):
        panel = self.make_popup(anchor)
        panel.button('타이머 설정', lambda: self.show_timer(anchor))
        panel.button('캐릭터 설정', lambda: self.show_characters(anchor))
        panel.display()

    def show_timer(self, anchor):
        panel = self.make_popup(anchor, '타이머 설정')
        running = self.model.state in ['running', 'paused']
        if running:
            panel.button('일시정지' if self.model.state == 'running' else '계속하기', self.pause_resume)
            panel.button('타이머 해제', self.stop)
        else:
            for minutes in [15, 30, 60]:
                panel.button(f'{minutes}분', lambda minutes=minutes: self.begin(minutes*60))
            panel.button('커스텀', self.show_custom)
        panel.separator()
        for attr, label in [('show_siren', '세이렌 표시'), ('sound', '완료 노래')]:
            button = panel.button(('✓ ' if getattr(self, attr) else '')+label, lambda: None, close=False)
            button.clicked.connect(lambda checked=False, attr=attr, label=label, button=button: self.toggle_option(attr, label, button))
        if not running:
            panel.button('종료', self.close)
        panel.display()

    def toggle_option(self, attr, label, button):
        setattr(self, attr, not getattr(self, attr))
        button.setText(('✓ ' if getattr(self, attr) else '')+label)
        if attr == 'sound' and not self.sound:
            self.player.stop()
        self.save_settings()
        self.update()

    def show_characters(self, anchor):
        panel = self.make_popup(anchor)
        for key, name in NAMES.items():
            button = panel.button(name, lambda key=key: self.select_character(key))
            button.setProperty('selected', key == self.character)
            button.style().unpolish(button)
            button.style().polish(button)
        panel.display()

    def select_character(self, key):
        self.character = key
        self.icon_frame = -1
        self.update_study_icon(self.clock())
        if self.model.state == 'finished':
            self.stop()
        self.save_settings()
        self.update()

    def show_custom(self):
        self.dismiss_settings()
        dialog = QDialog(self, Qt.WindowType.Dialog | Qt.WindowType.FramelessWindowHint)
        self.custom_dialog = dialog
        dialog.setAttribute(Qt.WidgetAttribute.WA_TranslucentBackground)
        dialog.setWindowTitle('커스텀 타이머')
        dialog.setFixedWidth(232)
        outer = QVBoxLayout(dialog)
        outer.setContentsMargins(16, 16, 16, 24)
        card = QFrame()
        card.setObjectName('customDialog')
        outer.addWidget(card)
        shadow = QGraphicsDropShadowEffect(card)
        shadow.setBlurRadius(24)
        shadow.setOffset(0, 8)
        shadow.setColor(QColor(0, 0, 0, 34))
        card.setGraphicsEffect(shadow)
        dialog.setStyleSheet('''QFrame#customDialog {background:white; border:0; border-radius:12px;}
            QLabel {color:#8a938d; background:transparent; font-size:12px;}
```

```python
"""Create a Windows shortcut for the timer using the current Python install."""
from __future__ import annotations

import argparse
import ctypes
from pathlib import Path
import sys
import uuid

ROOT = Path(__file__).resolve().parent


def find_pythonw() -> Path:
    # Use the interpreter that ran this script, including an activated venv.
    path = Path(sys.executable).resolve().with_name('pythonw.exe')
    if not path.is_file():
        raise FileNotFoundError('pythonw.exe was not found beside the current Python interpreter.')
    return path


def create_shortcut(destination: Path) -> Path:
    if sys.platform != 'win32':
        raise RuntimeError('Windows is required to create a .lnk shortcut.')
    script = ROOT / 'chiikawa_timer.py'
    if not script.is_file() or not (ROOT / 'assets').is_dir():
        raise FileNotFoundError('Keep create_shortcut.py, chiikawa_timer.py and assets in the same folder.')
    pythonw = find_pythonw()
    if destination.suffix.lower() != '.lnk':
        raise ValueError('The destination must end in .lnk.')
    destination = destination.resolve()
    destination.parent.mkdir(parents=True, exist_ok=True)

    class GUID(ctypes.Structure):
        _fields_ = [('Data1', ctypes.c_uint32), ('Data2', ctypes.c_uint16),
                   ('Data3', ctypes.c_uint16), ('Data4', ctypes.c_ubyte * 8)]

    def guid(value):
        return GUID.from_buffer_copy(uuid.UUID(value).bytes_le)

    HRESULT = ctypes.c_long
    ole32 = ctypes.OleDLL('ole32')
    ole32.CoInitializeEx.argtypes = [ctypes.c_void_p, ctypes.c_uint32]
    ole32.CoInitializeEx.restype = HRESULT
    ole32.CoCreateInstance.argtypes = [ctypes.POINTER(GUID), ctypes.c_void_p,
        ctypes.c_uint32, ctypes.POINTER(GUID), ctypes.POINTER(ctypes.c_void_p)]
    ole32.CoCreateInstance.restype = HRESULT
    ole32.CoUninitialize.argtypes = []

    def checked(result):
        if result < 0:
            raise OSError(f'Windows shortcut operation failed: 0x{result & 0xffffffff:08X}')

    def call(pointer, index, arguments, *values):
        table = ctypes.cast(pointer, ctypes.POINTER(ctypes.POINTER(ctypes.c_void_p))).contents
        method = ctypes.WINFUNCTYPE(HRESULT, ctypes.c_void_p, *arguments)(table[index])
        result = method(pointer, *values)
        checked(result)

    def release(pointer):
        if pointer.value:
            table = ctypes.cast(pointer, ctypes.POINTER(ctypes.POINTER(ctypes.c_void_p))).contents
            method = ctypes.WINFUNCTYPE(ctypes.c_ulong, ctypes.c_void_p)(table[2])
            method(pointer)

    initialized = ole32.CoInitializeEx(None, 2)
    checked(initialized)
    link, persist = ctypes.c_void_p(), ctypes.c_void_p()
    try:
        clsid = guid('00021401-0000-0000-C000-000000000046')
        iid = guid('000214F9-0000-0000-C000-000000000046')
        checked(ole32.CoCreateInstance(ctypes.byref(clsid), None, 1, ctypes.byref(iid), ctypes.byref(link)))
        call(link, 20, [ctypes.c_wchar_p], str(pythonw))
        call(link, 11, [ctypes.c_wchar_p], f'"{script}"')
        call(link, 9, [ctypes.c_wchar_p], str(ROOT))
        call(link, 7, [ctypes.c_wchar_p], '치이카와 타이머 3종 · Python')
        call(link, 15, [ctypes.c_int], 1)
        icon = ROOT / 'chiikawa_timer.ico'
        if icon.is_file():
            call(link, 17, [ctypes.c_wchar_p, ctypes.c_int], str(icon), 0)
        persist_iid = guid('0000010B-0000-0000-C000-000000000046')
        call(link, 0, [ctypes.POINTER(GUID), ctypes.POINTER(ctypes.c_void_p)],
            ctypes.byref(persist_iid), ctypes.byref(persist))
        call(persist, 6, [ctypes.c_wchar_p, ctypes.c_int], str(destination), 1)
    finally:
        release(persist)
        release(link)
        ole32.CoUninitialize()
    return destination


def main():
    parser = argparse.ArgumentParser(description='Create a local Windows shortcut for the Python timer.')
    parser.add_argument('--output', type=Path, default=ROOT / '치이카와 타이머.lnk',
                        help='Shortcut path; defaults to the program folder.')
    args = parser.parse_args()
    try:
        import PySide6.QtWidgets
        import PySide6.QtMultimedia
        destination = create_shortcut(args.output)
    except (ImportError, OSError, RuntimeError, ValueError) as error:
        print(f'Cannot create shortcut: {error}', file=sys.stderr)
        print('Install dependencies first: py -m pip install -r requirements.txt', file=sys.stderr)
        return 1
    print(f'Shortcut created: {destination}')
    print('Double-click the shortcut. You may copy it to your desktop.')
    print('Keep the program folder in place; recreate the shortcut if it moves.')
    return 0


if __name__ == '__main__':
    raise SystemExit(main())
```

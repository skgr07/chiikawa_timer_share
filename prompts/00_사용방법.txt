치이카와 타이머 3종 — GPT 재현 자료

목적
현재 최종 배포 ZIP의 Python 타이머를 같은 자료, 코드, 좌표, 메뉴, 모션으로 재현하기 위한 묶음입니다.
프롬프트만으로 매번 동일한 코드를 생성하는 것은 보장할 수 없습니다. 동일한 결과가 중요하다면 동봉한 기준 코드를 그대로 사용하고, 프롬프트는 구현 확인과 필요한 수정에 사용하세요.
모니터 배율, Windows/Qt 버전, 폰트 렌더링과 오디오 장치에 따라 화면과 소리에 작은 차이가 날 수 있습니다.

제공할 파일
1. GPT_제공파일.zip을 첨부합니다. 최종 자료 전체와 안내/프롬프트/상세명세가 들어 있습니다.
2. 01_GPT에_붙여넣을_전체프롬프트.txt의 내용을 메시지에 붙여넣습니다.
3. Python 프로그램 전체를 실제 파일로 만들고, 원본 assets를 그대로 복사해서 실행 가능한 ZIP으로 반환하도록 요청합니다.
4. 파일을 읽거나 코드 실행을 할 수 없는 환경이라면, GPT가 이를 알리도록 하고 기준코드/상세명세를 읽을 수 있는 환경에서 진행하세요. 이미지와 음악이 없는 상태에서 비슷한 대체 자료를 생성하면 동일한 결과가 나오지 않습니다.

자료 구성
- 01_GPT에_붙여넣을_전체프롬프트.txt: 요청문, 구현 순서, 기준 코드/필수 실행 파일의 전체 내용.
- 02_재현_상세명세.txt: 상태, 좌표, 색상, 메뉴, 애니메이션, 음악, 종료/저장과 검증 조건.
- GPT_제공파일/assets: 최종 배포 ZIP의 이미지·음악·폰트 원본. 바이트 단위로 동일한 자료입니다.
- GPT_제공파일/reference: 최종 코드, 실제 테스트, requirements, create_shortcut.py, 바로가기 아이콘, 출처 및 폰트 라이선스.
- GPT_제공파일/reference_images: Python 기준 코드로 직접 렌더링한 상태별 투명 PNG와 설정창 이미지.
- GPT_제공파일/기준정보.json: 배포 ZIP 식별 해시, 자산 해시/크기, 이미지 크기와 핵심 설정.
- GPT_제공파일/검증결과.txt: 기준 코드의 테스트 실행 결과.

받은 프로그램 실행
Windows 64비트용 Python 3.10 이상을 설치합니다. 기준 환경은 Python 3.12입니다.
GPT가 만든 폴더에서 터미널을 열고 다음을 실행합니다.
  py -m pip install -r requirements.txt
  py create_shortcut.py
생성된 ‘치이카와 타이머.lnk’를 더블클릭하면 콘솔 없이 타이머만 실행됩니다.
바로가기를 바탕화면에 복사해도 됩니다. 생성용 터미널을 닫아도 타이머는 유지됩니다.
프로그램 폴더를 옮기거나 Python 경로가 바뀌면 py create_shortcut.py를 다시 실행하세요.
라이브러리 설치와 바로가기 생성에는 같은 Python 환경을 사용하세요.
타이머의 Python 프로세스를 종료하면 타이머도 꺼집니다.
12초 체험은 다음을 사용합니다.
  py chiikawa_timer.py --demo --character usagi
  py chiikawa_timer.py --demo --character chiikawa
  py chiikawa_timer.py --demo --character hachiware

기준 프로그램 그대로 쓰기
새로 생성할 필요가 없으면 GPT_제공파일/reference 안의 chiikawa_timer.py, requirements.txt, create_shortcut.py, chiikawa_timer.ico와 출처/라이선스를 새 폴더에 복사하고, GPT_제공파일/assets 폴더를 같은 폴더에 복사하면 됩니다. test_timer.py는 검사할 때 사용합니다.

설정과 비교
기존 타이머를 사용한 PC에서는 %APPDATA%\chiikawa_timer_python\settings.json의 캐릭터/위치/옵션이 복원됩니다.
기준 이미지 생성에서는 persist=False와 고정된 시계를 사용하여 기존 설정에 영향받지 않도록 했습니다.
이미지/코드/수치 명세가 충돌하면 최종 배포 ZIP에서 추출한 reference/chiikawa_timer.py와 자산이 기준입니다.

공유 범위
이 묶음에는 EXE, Godot 프로젝트, MSIX, 개인 계정 정보나 기존 PC의 settings.json을 포함하지 않습니다.
이미지와 음악은 기존 배포본의 자료이며, 제공된 자료의 재배포 권한은 별도로 확인해야 합니다.
Python 소스로 직접 만들어도 Windows 스마트 앱 컨트롤의 허용이나 GitHub/Store의 안전성 인증을 보장하지 않습니다.

바로 실행할 수 있는 소스 배포본
‘바로가기_배포본/chiikawa_timer_python’ 폴더에는 소스와 assets가 바로 실행 가능한 구조로 있습니다.
‘치이카와_타이머_소스_바로가기.zip’은 이 폴더의 배포 ZIP입니다.
다운로드한 사용자는 압축을 모두 풀고 그 폴더에서 위의 최초 설치 두 명령을 실행하면 됩니다.
배포 ZIP에는 다른 PC에서 동작하지 않는 개인 경로의 .lnk를 넣지 않습니다.
각 사용자 PC에서 create_shortcut.py가 해당 PC의 경로로 .lnk를 만듭니다.
BAT/PowerShell 스크립트/EXE 설치 프로그램은 제공하지 않습니다.
